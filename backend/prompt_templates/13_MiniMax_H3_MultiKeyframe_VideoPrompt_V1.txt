#13 — MiniMax H3 arbitrary multi-semantic-control Prompt Builder
N 个语义 controls 不等于 N 张 Pictures；允许 holey IMAGE_BACKED/TEXT_ONLY，
也允许合法 EXTEND/TEMPORAL_EXTEND 中 M=0。
示例 KF1 有实际 first Picture、KF2/KF3 TEXT_ONLY、KF4 有实际 second Picture：
按 KF1→KF2→KF3→KF4 chronology，而不是跳过中间无图状态；
实际编号只可读 physical_picture_manifest，不能输出 Picture 3/4。
逐段按当前 canonical transition 描写视觉演进，不改变 owned/carry-in，
不因存在 temporal anchors 而增加语义控制数量或改变模板。

【Canonical manifest-aware projection】
semantic_control_count、owned_state_count、ordinary_reference_count、
temporal_anchor_count、previous_av_present 是独立概念。
#11/#12/#13 由 semantic control shape 选择，不由 physical Picture 数量选择。

visual_controls / ordered_keyframes 是当前 Clip owned canonical Visual States。
每个 state 保留 semantic_state_label（KF 编号）、role、Clip-local time_seconds、
description，以及 optional physical_picture。
IMAGE_BACKED: 只引用该 state 的实际 physical_picture。
TEXT_ONLY / physical_picture=null: 用 KF 编号、时间、视觉描述表达，不造图片编号。
semantic N → physical M；M 可小于 N，EXTEND/TEMPORAL_EXTEND 可为 0。

physical_picture_manifest 是唯一 <Picture N> authority；
只能使用其中 dense one-based Picture 1..M，不得从 KF index、role、position、
时间或 state count 推导编号。无 ordinary refs 时不能输出任何 Picture 标签。
实际 ordinary Picture 可为状态图或合法身份/场景/道具参考，不能全部当作时间状态。

Previous AV 是独立视频 conditioning：仅 conditioning.previous_av_present=true 时，
从所提供前视频的 ending visual state 继续。无 Picture 编号，不复述历史 Task。
temporal_anchors 是独立 timed conditioning：按给定 Clip-local time、
canonical state identity、description 表达目标；不编号为普通 Picture，不新增 semantic control。
carry_in_state_index 只是语义上下文，不成为 owned state 或物理 Picture。
物理绑定、workflow、Previous AV 来源由 compiler 负责，不由本 Prompt 决策。

【可靠输入与视觉范围】
只使用 safe structured Shot Character/Scene/Prop/official_character_appearances、
owned canonical visual_controls、Clip-local canonical transitions、motion_directive。
不从 raw Shot.description、video_description、raw dialogues 推断人声或新的剧情。
canonical dialogue_timeline_source 是唯一 speaker / exact text / timing authority，
不是视觉状态 authority。LLM 不输出 dialogue_timeline；程序统一注入并审计。
即使 Picture 有张嘴或角色很显著，也不分配说话者。
允许微笑、皱眉、嘴角变化、咬紧牙关、视线、身体前倾、转身、姿态、手势。

当前 Clip 是唯一执行范围；不重新规划状态、Clip 边界，不加入未来剧情。
每个 transition 只连接当前投影的相邻 canonical states（或 carry-in → first owned）。
按语义状态顺序描写动作执行者、方向与目标、摄影机和到达状态；
图像缺失不得导致跳过 TEXT_ONLY 状态，也不能把时间轴缩成已有 Pictures 顺序。
位置、姿势、朝向、视线和 framing 在对应时间锚点固定，之间自然演化。
稳定身份不漂移；当前服装与 stable identity 分离，历史默认服装不能覆盖。
有 actual Picture/Previous AV/temporal conditioning 时遵从其已建立视觉事实；
没有对应图像时遵从 canonical 文本与当前 appearance，不宣称看过不存在的图像。
不得无依据新增人物/道具、换装、镜像、瞬移、背景主体提升或重置场景。
Shot continuity_mode 是 guidance；不反推 Clip continuity 或物理 capability。
当前语义 Clip 的 CUT/CONTINUOUS 与实际 conditioning 决定跨 Clip 视觉关系；
独立 CUT 不声称继承 Previous AV。Clip 内动作、摄影机应自然服务其 transitions。

【人物身份连续性】
━━━━━━━━━━━━━━━━━━

同一角色跨所有 visual anchor 必须保持同一 Subject 身份。

最终 Prompt 必须输出 official_character_identity_lock
区块。该区块必须表达：

The referenced visual anchors are the primary visual authority for the
character’s currently established visual identity at their chronological
time anchors. The official character descriptions are
identity-preservation constraints used to prevent character drift across
frames. They supplement the referenced visual anchors but must not override
clearly visible identity features established by the visual anchors.

For every character: - Preserve stable identity: the same face, age,
body proportions, hair/mane, beard, fur/skin color, permanent markings,
stable physical features, identity-defining accessories, and overall
subject identity throughout the clip. - Current costume is a separate
continuity domain from stable character identity. Preserve the current
costume state established by the authoritative temporal visual anchor(s); do
not restore, layer, blend, or partially reveal a conflicting
historical/default costume from official_character_appearances. - Do not
redesign, reinterpret, beautify, age, de-age, recolor, or replace the
character. - Do not reinterpret shadows, dark lighting, color grading,
distance, motion blur, or environmental illumination as changes to fur,
skin, hair, or the current costume color. - Temporary pose, expression,
gaze direction, body orientation, spatial position, and physically
natural motion may change according to the transition segments. - If an
official stable-identity detail is not clearly visible in the referenced
visual anchors because of pose, occlusion, distance, or lighting, preserve
that stable-identity detail when it becomes visible. For costume
details, use the current temporal visual anchor(s) and current Shot
Appearance/costume binding as authority. - If a textual character
description directly conflicts with a clearly visible identity feature
in the referenced visual anchors, follow the referenced visual anchors for the
current visual identity.

保持： - 面部； - 发型/鬃毛/胡须； - 年龄； - 体型比例； - 毛色/肤色； -
永久标记； - 当前服装颜色、服装/甲胄/鞋履/可变配饰只服从对应时间锚点
visual anchor 与当前 Shot Appearance/costume
binding；不得由历史/默认服装描述覆盖； - official_character_appearances
中不可见或不清晰的身份细节在重新可见时必须恢复/保持；不得因暗光、阴影、冷色调、距离或运动模糊，把浅色服装/毛色/发色改写成黑色/深色； -
角色唯一性。

不得： - 人物复制； - 身份交换； -
角色突然消失/出现（除非正式关键帧和剧情明确要求且仍符合
shot.characters）； - 左右关系无依据镜像翻转； - 场景无依据重置。

旁白永不成为 Subject。

群体角色始终作为群体。

【当前服装权威 / Current Costume Authority】
━━━━━━━━━━━━━━━━━━

稳定 Character Identity 与 Current Costume 必须分离。

权威顺序： 1. 当前时间锚点 visual anchor 中清楚可见的服装状态； 2. 当前 Shot
的 Character Appearance / costume
binding（如提供，仅用于补充锚点中被遮挡或不可见的当前服装细节）； 3.
official_character_appearances 中仅与当前服装不冲突的稳定身份信息。

禁止： - 用角色历史/默认服装覆盖当前 visual anchor 已建立的服装； -
在当前服装外叠加旧外袍、旧甲胄或第二套服装； -
把当前服装与旧服装的颜色、纹样、材质融合； -
因阴影、调色、距离或运动模糊误判服装颜色。

多关键帧特殊规则： - 每张 visual anchor 是其对应时间点的服装状态权威。 -
如果所有 chronological visual anchors 显示同一套服装，则整个 Clip
只能保持这一套服装。 - 如果正式关键帧明确表现真实换装，则服装只能按
visual anchor
时间顺序连续变化；不得提前出现后续服装，不得把前后两套服装混穿或融合。 -
official_character_appearances 无权制造关键帧中不存在的换装。

【Subject 引用规范】
━━━━━━━━━━━━━━━━━━

角色标准名只允许在 subject_definitions 中用于首次建立 Subject 映射：

<Subject 1> is 角色标准名, ...
<Subject 2> is 角色标准名, ...

完成首次映射后，后续所有区块必须只使用 <Subject N> 引用人物，不得再次直接使用角色标准名代指人物。

<Subject N> 必须始终保持完整、独立、不可变。

subject_definitions 必须严格按输入 clip_visible_characters 的顺序建立映射：
第一个可见角色为 <Subject 1>，第二个为 <Subject 2>，依此类推。
subject_definitions 只定义人物身份、稳定外观和当前服装连续性，不得写 silent、
non-vocal、speaking、speech、voice、vocalization、lip-sync 或发声权限。

允许：
<Subject 1> turns toward <Subject 2>.
the face of <Subject 1>
the movement of <Subject 2>

禁止：
<Subject 1>'s
<Subject 2>s
<Subject 3>-like

需要表达所属关系时，使用 “the ... of <Subject N>”，或直接改写为以 <Subject N> 为主语的完整动作句。

Character names, Subject labels, and role labels are metadata identifiers only. They are never spoken content. Never vocalize, pronounce, read aloud, or synthesize any character name, Subject label, role label, or metadata token.

唯一例外：如果相同文字逐字存在于合法 clip_dialogues / exact_dialogue / optional_narration 中，则它作为合法语音原文保留，但只由程序注入的 dialogue_timeline 承载。

【人声权限委托】
━━━━━━━━━━━━━━━━━━

人声、旁白、对白前后额外发声、说话后的口型与静音权限全部委托 canonical
dialogue_timeline；LLM 的任何输出区块均不得再次描述这些规则。视觉反应只写
自然表情、姿态和视线；环境声只写 room tone、footsteps、fabric rustle 等非人声。

【台词硬约束】
━━━━━━━━━━━━━━━━━━

程序注入的 dialogue_timeline 是当前 Clip 唯一合法人物对白正文源。

最终 Prompt 中每条 exact_dialogue 正文只能完整出现一次，只能出现在
dialogue_timeline 区块。
detailed_description、summary、overall_soundscape、subject_definitions、keyframe_timeline
等其他区块不得再次复制 exact_dialogue 正文。
其他视觉区块仅可把 assigned dialogue D1 / D2 等作为时间事件标记，不得写出原文，
也不得以事件标记重新说明谁发声、谁沉默或谁做口型。

视觉关键帧时间轴与台词时间轴相互独立。 KF1 → KF2、KF2 → KF3 只是视觉 transition 边界，不是台词起止边界。
Visual keyframe boundaries are visual-state boundaries only. Assigned dialogue event IDs
may continue across a visual transition boundary. Do not reinterpret, restart, truncate,
duplicate, or reassign an assigned dialogue event because of a visual-state boundary. All
dialogue authority remains exclusively in the canonical dialogue_timeline.

对于每条实际人物台词：

speaker / character_name 只用于程序解析到对应 <Subject N>。不得在 LLM 输出中写
speaker、start/end、exact_dialogue 或第二个 dialogue_timeline。
其他段落只可引用 D 编号作视觉注意力和节奏标记，例如镜头平稳偏向事件对应的
视觉焦点；不得写事件何时开始或结束、对应人物的发声与口型变化，也不得因事件
自动切镜或频繁摇镜。绝不由摄影机、Picture 或嘴型反推对白。

不得在 detailed_description 或 overall_soundscape 复述 exact_dialogue 原文，
也不得在这些区块重新指定人物发声权限或人声前后规则。

如果多条 dialogues： - 按输入顺序与当前 Clip 的合法时序引用 D 编号； -
不交换说话者； - 不合并文本。

overall_soundscape 保持与场景匹配的可听环境声与 Foley，不把无人声误写成整个

无关声源或音乐。人声和人物静音约束仅在 canonical dialogue_timeline 中。

【输出结构】
只输出最终 H3 Prompt 正文，不输出 JSON、不解释、不输出 [Shot 2]。

subject_definitions:
严格按 clip_visible_characters 建立 <Subject N> is 标准名。
无人 Clip 不虚构 Subject；只写身份、可见外观和当前服装，不定义发声/静音/口型。

official_character_identity_lock:
保持稳定脸、年龄、体型、肤色/毛色、发型、永久标记、身份配饰。
可用的实际 visual conditioning 建立当前视觉事实；official appearances 防漂移，
不恢复冲突的历史/默认服装，不混穿、叠穿、混色。暗光、阴影、距离、调色不是换色。

keyframe_timeline:
逐个写 KF identity、role、Clip-local time 和视觉状态；
有 physical_picture 才引用实际 manifest 标签；TEXT_ONLY 仅写 KF 与文本。
chronology 按 semantic states，不按已有图片数量。
所提供 temporal targets 可在单独视觉 target 描述中按时间引用，不能变成普通 Picture。
Previous AV 存在时明确继续其 ending visual state，无 Picture 编号。

summary:
仅概括当前 Clip 场景、调度、视线、姿态、表情和镜头推进，不定义人声规则。

detailed_description:
[Shot 1] 根据当前语义控制和局部 transition 写视觉演进。
相邻段分别描述，不混合全部动作；不把身份锁误当站位永久锁。
可引用 assigned dialogue D 编号作视觉节拍，不写 exact text、
speaker/起止/口型/发声权限，不从嘴部或画面位置反推对白。
到达当前最后语义状态后不发展新剧情。

overall_soundscape:
只写与环境、材质、距离、可见动作一致的 ambience / room tone / Foley，
movement/object interaction sounds 和适当 non-human sound；
不把 NO_VOICE 当 SILENT_AUDIO，不关闭音轨，不凭空造音乐或声源。
全部人物语音规则委托程序注入的 canonical dialogue_timeline，不能在此重写。

【输出前内部自检】
- 语义控制数量与普通图片数量是否分开？
- TEXT_ONLY 是否仅文本表达，无不存在的 <Picture N>？
- 图片标签是否完全来自 final ordinary manifest，编号 dense、时间正确？
- Previous AV/temporal/carry-in 是否保持分离，没有普通 Picture 编号？
- 所有合法视觉状态与 transition 是否按当前 Clip 顺序/时间保留？
- 稳定人物身份、当前服装、自然动作与镜头是否保持？
- 是否无 dialogue_timeline / speaker / exact_dialogue 复写、无另行发声/口型规则？
- 零对白 NO_VOICE 由程序注入，环境/Foley 仍可听，而不是 silent audio？
- 是否只处理当前 Clip，无新增剧情/角色/字幕/水印？
