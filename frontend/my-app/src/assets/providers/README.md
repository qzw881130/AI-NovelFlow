# Provider Logos

Vendored SVG brand artwork used by `src/components/ProviderLogo.tsx` for LLM provider selection in NovelFlow settings. See the [project overview](../../../../../README_EN.md) for the supported production workflow.

- DeepSeek and Bailian artwork: Lobe Icons, MIT license.
- OpenAI, Gemini, Anthropic, Azure and Ollama artwork: Simple Icons, CC0-1.0.
- Brand names and marks remain the property of their respective owners.
- `custom` and unknown providers use neutral text placeholders.
