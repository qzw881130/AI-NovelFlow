# 第六阶段：宫格模式 API 与生成服务

## 已接通

- 原创建／编辑小说表单提交 `videoMode` 与当前模式专用提示词绑定。新小说默认宫格；既有小说及不传模式的旧 API 调用继续单镜。已有 Shot 时不能切换模式。
- 原章回生成入口按小说模式进入宫格页面或原单镜页面。旧小说的正式 Phase B 路径继续使用原组件。宫格小说调用单镜主图与视频生成入口会得到模式提示，避免混写。
- 宫格接口按顺序完成：章回正文拆成叙事 Shot；每 Shot 自动随机 2×2／2×3 或手选实验性 3×3 并保存；规划完整子格；预览整板提示词、尺寸和实际参考素材；生成整板并按阅读顺序裁成 16:9 子格；逐格通过、标记失败、重做或上传替换；依据原文台词规划不超过 20 秒的 Clip；选裁切子格或整板直传；预览并校验 H3 六段式提示词；生成或重做 Clip；合并 Shot 与章回视频。
- 整板生图沿用当前已激活的 Shot 工作流，明确映射宽、高、角色、场景和道具参考位。双人以上角色身份图先合并到现有单一角色参考位。生成提示词的 LLM 能看到实际参考图的缩略视觉输入；预览后的生图参考素材若变化，生成会停下要求重新预览。
- H3 沿用当前多参考工作流，默认只传当前 Clip 的子格图；整板直传须显式选择。白底角色设定图不作为 H3 普通子格传入。编译提示词的 LLM 同样看到实际子格／整板视觉输入。H3 工作流提交前检查 `ref_image_size=match`；提示词六段结构、Subject 定义位置、人物名字位置、Picture 编号、原文台词和时间范围经校验，失败不提交 ComfyUI。任务记录输入参考图、最终提示词、模板正文与工作流快照。
- 章回图片统计和小说封面可读取宫格整板；单镜模式仍读取 `Shot.image_url`。

## 审核入口与下一阶段边界

用现有「创建小说」弹窗创建宫格小说，从章回的原「生成」入口进入新页面；旧小说仍进入原页面。静态 `/grid-preview` 样例页仍可用于比对，但真实数据与 API 已在原入口接通。

本阶段的长耗时生成接口仍同步等待请求；页面显示进行中并要求保持打开。第七阶段将接入现有任务队列、批量顺序执行、取消／重试和关闭页面后的进度恢复。第八阶段再用真实 ComfyUI／H3 生成和人工审片验证画面、台词、合片；本阶段尚未实际提交新的生图或视频任务。
