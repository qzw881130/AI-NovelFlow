# 第七阶段：宫格模式接入现有任务队列

## 本阶段完成

- 宫格拆 Shot、规划子格、生成整板提示词与图片、规划 Clip、编译 H3 提示词、生成 Clip、合并 Shot／章回均改为提交持久任务；请求立即返回任务 ID，页面可关闭后再查看进度。
- 使用现有 `Task`、`BackgroundJob` 和单线程 FIFO worker。整板和 Clip 支持按章回顺序批量提交；每一项有独立任务，上一项失败时后续项停止，批量任务显示失败位置。没有增加并发调度平台。
- 宫格任务输入保存小说模式、版式修订、子格编号、参考图、提示词、模板正文、工作流快照及 ComfyUI prompt ID。已提交图片／视频任务在服务重启后按原 prompt ID 等待结果，不重新提交同一物理任务。
- 取消运行中的宫格任务不会终止整条串行队列；结果落库前检查取消状态。合片产物与任务完成状态在同一事务提交。启动时修复“子任务已完成、批量父任务尚未更新”的短暂状态。
- 任务列表复用现有接口，宫格页面可查看进度、错误、取消和从失败步骤重新排队。单镜图模式继续走原任务与正式 Phase B 路径。
