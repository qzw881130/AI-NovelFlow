# 第三阶段审核：宫格模式静态前端

范围：固定第一章实验样例的前端预览，不接小说保存、生成 API、任务队列或 ComfyUI。

章回预览入口：`/novels/<novelId>/chapters/<chapterId>/grid-preview`。这是独立路由；现有 `/generate` 单镜页面及 Phase B 控件未被替换。预览页提供返回原单镜页的链接。小说模式控件直接放在原有 `/novels` 的创建／编辑弹窗内，不另设表单预览入口。

已完成：
- 原有创建小说弹窗增加模式选项，初始选宫格；宫格时展示共用模板和四个宫格专用模板占位，隐藏单镜专用模板。由于后端尚无模式字段，宫格创建按钮暂时禁用并说明原因。切换单镜后，原有模板选项与创建流程仍可使用，提交时不会把预览字段发给后端。
- 原有编辑小说弹窗显示既有小说属于单镜模式，模式选择暂时只读；其余编辑和模板选择保持原行为。真实的模式保存及 Shot 锁定判断留待后续阶段。
- 章回页按叙事 Shot 展示三个固定样例，子格留在各自的 Shot 内。顶部保持原流程的分镜拆分、分镜图生成、视频生成位置。
- 分镜拆分页可查看 2×2 / 2×3 版式示意，3×3 标注为实验候选；宫格生图页展示整板和逐格裁切预览、镜头术语、评审状态与格到 Clip 的对应。尚无 API 的评审及重试按钮为禁用状态。
- 视频生成页可选 Clip，预览该 Clip 的实际 Picture 子格顺序、台词、说话人和六段式 H3 文本；右侧保留最终 Shot 视频和 Shot／章回结果的位置。提示词中的 Subject 编号跨样例 Clip 保持同一角色绑定。
- 使用第一章实验中已审核的三张 2×2 宫格整板压缩为静态资源。2×3 目前只演示版式格子，不冒充已生成的六格图。

验证：前端 TypeScript 检查及 `git diff --check` 通过。浏览器检查了整板、视频页、原有创建弹窗的宫格／单镜切换、单镜创建按钮可用、原有编辑弹窗的单镜只读状态，以及回到原单镜页的链接。

后续：第四阶段将模式选择接入真实小说创建与编辑表单；第五阶段再建立持久化结构。此阶段的样例状态、评审、提示词和视频占位均非真实任务数据。
