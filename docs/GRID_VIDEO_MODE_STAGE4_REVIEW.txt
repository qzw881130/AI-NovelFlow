# 第四阶段：小说模式表单与宫格页面操作入口

## 本阶段改动

- 原有创建小说弹窗默认宫格模式，切换单镜模式后继续使用原创建接口。宫格创建按钮保持禁用，直到模式字段存储与 API 接通，避免误写成单镜小说。
- 原有编辑小说弹窗依据小说返回的 `videoMode` 显示模式；历史小说缺字段时按单镜显示。`hasShots` 为 false 且模式字段已持久化时可在表单中预览模式切换。真正保存模式变更仍须等待存储与 API 阶段。
- 模板选择按模式筛选。宫格仅列共用素材类与四个宫格专用模板，单镜保留原有 20 项。快速参考只列同模式小说；单镜创建接口只提交原有字段。小说卡片和小说详情显示模式。
- 对照单镜页补齐宫格静态预览的操作入口：本章 AI 拆分与保存分镜、当前宫格与本章批量生图、上传与重做、Clip 规划与生成、本 Shot／本章批量视频、Shot／章回合片及导出。这些按钮明确禁用，待生成 API 接入。角色、场景、道具三个小说级 AI 解析保留在现有全局入口，不在章回页重复。

## 旧流程对照

| 需求 | 现有单镜位置 | 宫格预览位置 |
| --- | --- | --- |
| 小说素材解析 | 小说卡片 AI 解析菜单 | 沿用小说卡片，不重复 |
| 章回 AI 拆分 | 分镜拆分页；小说详情有批量拆分 | 分镜拆分页；批量拆分沿用小说详情 |
| 生图与批量生图 | 分镜图页 | 宫格整板与逐格页 |
| 视频生成与批量生成 | 视频生成页 | Clip 页面，分 Shot／本章两级 |
| 合片 | 视频生成页；小说详情合并所有章回 | Clip 页面合 Shot／合章回；全书合片沿用小说详情 |

## 验证与后续边界

- `npx tsc --noEmit` 与 `git diff --check` 通过。
- 后端尚无模式字段、宫格模板绑定列和 `hasShots` 响应，故本阶段不声称宫格小说可保存。第五阶段补存储；第六阶段接入 API 并解除相应禁用。
- 本阶段未改动单镜 Shot、Phase B 生成与合片服务。
